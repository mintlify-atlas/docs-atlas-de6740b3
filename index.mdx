`get_next_line` is a lightweight, dependency-free C function that reads one line at a time from any file descriptor — files, standard input, pipes, or sockets. Call it repeatedly to iterate through every line in a source, and it returns `NULL` when the stream is exhausted. The bonus variant extends this to support up to 10,240 simultaneous open file descriptors, each tracked independently.

## How it works in three steps

<Steps>
  <Step title="Include the header">
    Copy `get_next_line.c`, `get_next_line_utils.c`, and `get_next_line.h` into your project and include the header.
  </Step>
  <Step title="Compile with BUFFER_SIZE">
    Pass `-D BUFFER_SIZE=<n>` to your compiler to control how many bytes are read from the fd per syscall.
  </Step>
  <Step title="Call in a loop">
    Call `get_next_line(fd)` repeatedly. Each call returns the next line (including the trailing `\n`) until the stream is empty, at which point it returns `NULL`.
  </Step>
</Steps>
